# OpenSight

AI-powered mobile application supporting visually impaired users in reading Vietnamese documents.

## Overview

OpenSight is a mobile application designed to assist visually impaired users in accessing printed documents, tables, and text through AI-powered image processing, text recognition, summarization, and text-to-speech.

## Tech Stack

- **Mobile:** React Native, Expo, TypeScript
- **AI Backend:** FastAPI, Python
- **Core Backend:** Spring Boot, Java
- **Database:** PostgreSQL
- **AI:** OCR, Vietnamese Text Summarization
- **Speech:** Text-to-Speech

## Project Structure

- `mobile/` - Mobile application
- `backend/ai-service/` - AI processing services
- `backend/core-service/` - Core backend services
- `docs/` - Project documentation
- `infrastructure/` - Infrastructure and deployment configurations
